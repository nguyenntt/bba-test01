## Homework lesson 04

### A. Ôn lại Git

| Lệnh                             | Ý nghĩa                                                             |
| -------------------------------- | ------------------------------------------------------------------- |
| `npm.cmd init playwright@latest` | Khởi tạo **Playwright project**                                     |
| `git init`                       | Khởi tạo **Git repository local** cho project                       |
| `git add .`                      | Đưa các file thay đổi từ **Working Directory → Staging Area**       |
| `git commit -m "..."`            | Chốt snapshot trong **Git repository local**                        |
| `git remote add origin "link trên repo...`      | ConnectHub                                           |
| `git push origin main`           | Đẩy các commit từ **local repository → remote repository** (GitHub) |
|` git config --global user.name `| Cấu hình user.name cho toàn dự án trong máy|
|` git config  user.name `| Cấu hình user.name cho toàn dự án hiện tại|

Lên (GitHub) tạo repo để có chỗ push code lên
